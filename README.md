# 余白のゲーム室

広告・会員登録なしで遊べる、スマホ向けの定番ゲーム集。ビルドもサーバー側の処理も不要な静的サイトです。

**プレイする: https://a2m-m.github.io/yohaku-sudoku/**

## 9つのゲーム

| ゲーム | 操作・機能 |
| --- | --- |
| お絵描きロジック | 5×5・10×10の絵解き、塗る/×/消す、1マスヒント、元に戻す、問題別の途中保存 |
| ウッドパズル | 9×9盤面・3個の手持ち、縦/横/3×3の同時消去、タップ/ドラッグ配置、元に戻す、ベスト記録 |
| オセロ | 3段階のコンピューター対戦・2人対戦、置ける場所表示、おすすめの一手、待った、自動パス、途中保存 |
| マインスイーパー | 3難易度、初手と周囲8マスが安全、開く/旗モード、数字の周囲を一括開き、同じ盤面に再挑戦 |
| 数独 | 難易度5〜10の100問、メモ、候補記入、無制限ヒント、元に戻す |
| ソリティア | クロンダイクの1枚めくり、タップ選択→移動先、自動基礎送り、次の一手、元に戻す、同じ配札 |
| フリーセル | 4つの待避マス、空き容量に応じたまとめ移動、自動基礎送り、次の一手、元に戻す |
| 15パズル | 必ず解ける初期配置、隣接タイルをタップ、元に戻す、手数・タイム |
| 2048 | スワイプ・矢印キー・方向ボタン、元に戻す、ベスト記録、2048達成後も続行 |

各ゲームの初回に遊び方を表示し、プレイ中も「遊び方」から確認できます。ゲームを切り替えても続きから再開できます。カードゲームはランダム配札のため、全配札のクリア可能性は保証していません。

保存は端末・ブラウザごとです。同期は行いません。ブラウザのサイトデータを削除すると進捗も消えます。保存が失敗した場合は通知し、ゲーム集を開いている間はメモリで途中経過を保持します。数独は通常300手/再読込後25手、カードは60手、数字ゲームは40手を元に戻せます。

初回読み込みとService Workerのキャッシュ完了後はオフラインでも利用できます。iPhoneはSafariの共有メニューから「ホーム画面に追加」で、すぐに起動できます。

## 構成と既存進捗の互換性

- `index.html` / `src/room.mjs` / `room.css`: ゲーム一覧、ハッシュルーター、遊び方。
- `sudoku.html` / `src/app.mjs`: 従来の数独。問題データ・問題ID・保存キー `yohaku-sudoku:v1:` は維持しています。
- `games/{mines,cards,numbers,reversi,nonogram,wood}.mjs`: DOMを構築する各ゲーム。`mount(container, {id, notify, onUpdate})` がイベント・タイマーを解除して保存するcleanup関数を返します。
- `games/*-engine.mjs`: DOMに依存しないルールと保存データ検証。
- 新規ゲームの保存キーは `yohaku-games:v1:<ゲームID>`。各ゲームに独立した進捗を保存します。
- `sw.js`: 全ゲームと数独データを事前キャッシュ。古い数独専用キャッシュは更新時に整理します。

ゲームを追加するときは、ルーターのゲーム定義・オフライン用アセット一覧・意味のあるルールテストも更新してください。

## 数独の問題と難易度

100問はそれぞれ独立したランダム完成盤から生成し、ヒントの数字を削除するたびに一意解を検証しています。回転や数字の置き換えだけによる問題の水増しはしていません。すべての問題について一意解・正解の全行/列/ブロック・手がかり保持・難易度の再計算をテストしています。

レベルは本アプリ独自の10段階評価で、他アプリの数値と同じ基準ではありません。手がかり数のみでは判定せず、シングル・ロック候補・裸のペアを順に適用した後の探索分岐数も使用します。探索量は人間が感じる難しさを完全には表さず、より高度な手筋では論理的に解ける問題も含みます。

| レベル | 問題数 | 基準 |
| --- | ---: | --- |
| 5 | 20 | ロック候補を必要とする |
| 6 | 20 | 裸のペア、またはロック候補4回以上 |
| 7 | 20 | 上記の手筋後の探索分岐1〜3 |
| 8 | 15 | 探索分岐4〜12 |
| 9 | 15 | 探索分岐13〜40 |
| 10 | 10 | 探索分岐41以上 |

正本は `src/sudoku.mjs` の `ratePuzzle()` と `scripts/generate-puzzles.mjs`。標準seedは `20261103` です。公開済みコレクションの問題IDを維持するため、運用中に `puzzles.json` を差し替える場合は保存キーのバージョンとService Workerのキャッシュ名も更新してください。

## ローカルで起動

Node.js 22以降。依存パッケージのインストールは不要です。

```sh
npm run dev
```

`http://localhost:4173` を開きます。スマホから同じWi-FiのPCに接続する場合は、PCのLANアドレスとポート4173を使ってください。LAN上のHTTP接続ではService Workerは使えません。

```sh
npm test       # 全ゲームのルール・問題・状態を検証
npm run generate  # 問題を再生成（既存問題を上書きするので通常は不要）
```

## GitHub Pages

リポジトリの **Settings → Pages → Deploy from a branch → main / (root)** で公開できます。`.nojekyll` 同梱。パスはすべて相対指定のため、`https://<ユーザー名>.github.io/<リポジトリ名>/` でそのまま動きます。

GitHub Pagesの公式手順: <https://docs.github.com/en/pages/quickstart>

UIやコードを更新する際は `sw.js` のキャッシュ名も更新し、古いオフラインキャッシュが残らないようにしてください。フォント・画像・分析・広告などの外部通信はありません。

## オセロ追加（2026-11-04）

直接開く: https://a2m-m.github.io/yohaku-sudoku/#reversi

- コンピューター対戦はあなたが黒。強さは「やさしい / ふつう / 手ごわい」。難易度は途中でも変更できます。
- 2人対戦は同じ画面を交互にタップ。打てない側は自動でパスし、両者とも打てないと空きマスがあっても終了。石数が同じ場合は引き分けです。
- CPU対戦の「元に戻す」は人間の手番まで、2人対戦では1手前に戻ります。CPU待機中でも取り消せます。
- CPUの探索には時間・ノード数の上限を設け、画面を離れたら予約した応手をキャンセルします。別ゲームへの移動や再読み込み後は続きから再開します。
- 保存キーは `yohaku-games:v1:reversi`。最大60手の履歴を保持し、復元時は初期配置から全手を再生して保存データの整合性を検証します。履歴を途中で切り詰めないでください。
- 全156テストが成功。8方向反転、自動パス、空きあり終局、引き分け、12対局の保存復元、AIの合法手と探索制限を検証。
- 390pxのブラウザでCPUの応手、保存復元、待った、おすすめ、難易度変更、2人対戦を確認。2人対戦を60手最後まで進め、黒19対白45で白の勝ちを表示しました。
- ローカルHTTPサーバー停止後に再読み込みし、2手目のCPU対戦とおすすめ表示を復元。390pxで横方向のはみ出しやブラウザのエラーログはありません。

ルール参照: [オセロ公式サイト](https://www.megahouse.co.jp/othello/what/)、[日本オセロ連盟競技ルール](https://www.othello.gr.jp/rule)。

## お絵描きロジック・ウッドパズル追加（2026-11-04）

- お絵描きロジック: https://a2m-m.github.io/yohaku-sudoku/#nonogram
- ウッドパズル: https://a2m-m.github.io/yohaku-sudoku/#wood

お絵描きロジックは、オリジナルのピクセル絵24問（5×5が8問、10×10が16問）。全問、行・列のヒントから解が1つに決まることを検証しています。塗る/×を付ける/消す、なぞり入力、1ジェスチャー単位のUndo、1マスヒント、間違い確認、問題集、完成時の絵の名前表示に対応。塗るべきマスがすべて合えば完成し、空白をすべて×にする必要はありません。

問題は `games/nonogram-puzzles.mjs`、保存は `yohaku-games:v1:nonogram:<問題ID>`。問題番号は配列の順番から作るため、公開済みの問題の並び・絵を変更しないでください。追加は末尾に行い、一意解を検証します。問題を差し替える場合は保存キーのバージョンも変更します。

ウッドパズルは9×9盤面に3個の手持ちを置く、回転・制限時間なしのブロックパズルです。縦1列・横1列・3×3を同一盤面で判定し、重なった消去マスは1回だけ消します。3個すべて置くと次の3個へ。タップ選択→左上の配置マスをタップ、ドラッグの両方で操作できます。

ウッドの得点は配置マス数＋消去マス数＋消した行/列/区画の数×10。保存キーは `yohaku-games:v1:wood`、ベストはその `:best`。Undoで手持ちの再配布や得点も戻りますが、ベスト記録は減りません。配置できる形がある盤面では、新しい3個のうち少なくとも1個を置けるようにしています。

検証: 全173テストが成功。ブラウザ幅390pxで、塗る/×/なぞり/Undo/保存復元/絵の完成/次問/10×10の表示/間違い確認、ウッドのタップ/ドラッグ/3個消費後の再配布/Undo/再読み込みを確認。ウッドは11点からUndoして7点に戻り、ベスト11点を保つことも確認しました。ローカルサーバー停止後もウッドの盤面とベストを復元し、一覧からお絵描きロジックの10×10問題へ移動できました。両画面とも390pxで横方向のはみ出しはありません。
