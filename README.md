# 余白の数独

広告・会員登録なしで遊べる、スマホ向けの数独アプリ。ビルドもサーバー側の処理も不要な静的サイトです。

**プレイする: https://a2m-m.github.io/yohaku-sudoku/**

## 遊ぶ

- マスを選び、下の数字キーで入力。
- メモ、候補の一括記入、元に戻す、消去、回数制限のないヒント。
- 途中の盤面・メモ・経過時間・クリア状態はブラウザに自動保存。
- 問題集から難易度や問題を自由に選択。途中の問題も続きから再開。
- 「遊び方と設定」で間違いの自動表示を切り替え。
- 初回の読み込みとService Workerのキャッシュ完了後はオフラインで利用可能。
- iPhoneではSafariの共有メニューから「ホーム画面に追加」で、すぐに起動できます。

保存は端末・ブラウザごとです。同期は行いません。ブラウザのサイトデータを削除すると進捗も消えます。通常は最大300手、再読み込み後は直近25手を元に戻せます。

## 問題と難易度

100問はそれぞれ独立したランダム完成盤から生成し、ヒントの数字を削除するたびに一意解を検証しています。回転や数字の置き換えだけによる問題の水増しはしていません。すべての問題について一意解・正解の全行/列/ブロック・手がかり保持・難易度の再計算をテストしています。

レベルは本アプリ独自の10段階評価で、他アプリの数値と同じ基準ではありません。手がかり数のみでは判定せず、シングル・ロック候補・裸のペアを順に適用した後の探索分岐数も使用します。探索量は人間が感じる難しさを完全には表さず、より高度な手筋では論理的に解ける問題も含みます。

| レベル | 問題数 | 基準 |
| --- | ---: | --- |
| 5 | 20 | ロック候補を必要とする |
| 6 | 20 | 裸のペア、またはロック候補4回以上 |
| 7 | 20 | 上記の手筋後の探索分岐1〜3 |
| 8 | 15 | 探索分岐4〜12 |
| 9 | 15 | 探索分岐13〜40 |
| 10 | 10 | 探索分岐41以上 |

正本は `src/sudoku.mjs` の `ratePuzzle()` と `scripts/generate-puzzles.mjs`。標準seedは `20261103` です。公開済みコレクションの問題IDを維持するため、運用中に `puzzles.json` を差し替える場合は保存キーのバージョンとService Workerのキャッシュ名も更新してください。

## ローカルで起動

Node.js 22以降。依存パッケージのインストールは不要です。

```sh
npm run dev
```

`http://localhost:4173` を開きます。スマホから同じWi-FiのPCに接続する場合は、PCのLANアドレスとポート4173を使ってください。LAN上のHTTP接続ではService Workerは使えません。

```sh
npm test       # 問題・ゲーム状態の検証
npm run generate  # 問題を再生成（既存問題を上書きするので通常は不要）
```

## GitHub Pages

リポジトリの **Settings → Pages → Deploy from a branch → main / (root)** で公開できます。`.nojekyll` 同梱。パスはすべて相対指定のため、`https://<ユーザー名>.github.io/<リポジトリ名>/` でそのまま動きます。

GitHub Pagesの公式手順: <https://docs.github.com/en/pages/quickstart>

UIやコードを更新する際は `sw.js` のキャッシュ名も更新し、古いオフラインキャッシュが残らないようにしてください。フォント・画像・分析・広告などの外部通信はありません。
